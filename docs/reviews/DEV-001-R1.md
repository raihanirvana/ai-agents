
Hasil: build berhasil, **5/5 tests passed**, npm audit **0 vulnerability**.
`pip-audit -r apps/backend/requirements.lock --no-deps --disable-pip` dari
venv audit terpisah: **No known vulnerabilities found**. Ini hasil audit saat
review, bukan jaminan tidak akan ada advisory baru.

Integration check tambahan memakai harness sementara `/tmp/dev001-r1-integration.mjs`:
menjalankan web/API subprocess, Playwright Chromium, menghentikan/memulai API,
memeriksa CORS, dan mengirim sinyal worker. Harness membuat `.env.local` sementara
hanya jika file belum ada, lalu menghapusnya dalam cleanup. Semua proses test
ditutup. Screenshot lokal: `test-results/r1/connected.png` dan `unavailable.png`
(gitignored). Bukti teks dalam report ini tetap dapat dilacak.

Untuk mengulang manual: jalankan tiga layanan seperti README, buka halaman,
hentikan API dan tunggu status unavailable, lalu hidupkan kembali tanpa reload.
Ulangi worker dengan SIGINT/SIGTERM. Untuk konfigurasi port, salin env example,
ubah WEB_PORT/API_PORT/VITE_API_BASE_URL/CORS_ORIGINS secara konsisten dan restart.
