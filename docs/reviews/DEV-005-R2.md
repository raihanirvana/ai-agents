image `node:22.20.0-alpine`. Test dijalankan dari root checkout dengan Git
yang benar di PATH. Invocation awal dari working directory backend mendapatkan
Git berbeda yang menolak `--initial-branch`; itu kegagalan setup, bukan test pass.

  test mencakup timeout lalu sukses dan penolakan hash salah.

  198.66 detik (`/tmp/dev005-r2-recheck.xml`). Rebuild nyata berhasil.

  filesystem + review regressions: **38 passed** dalam 3.39 detik

- Gabungan hasil terbaru per test ID dari tiga run JUnit: **103 test unik lulus**

- `git diff --check` dan compile package Python lulus. `docker ps -a` dengan
