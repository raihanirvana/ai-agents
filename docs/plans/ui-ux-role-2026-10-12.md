# Rencana role UI/UX dan spesifikasi UI — 12 Oktober 2026

Status: rencana disetujui pengguna untuk dikerjakan bertahap. Keputusan desain:
[docs/decisions/ui-ux.md](../decisions/ui-ux.md). Tiket: DEV-018 s.d. DEV-028 di
[IMPLEMENTATION-BACKLOG.md](../../IMPLEMENTATION-BACKLOG.md).

## Latar belakang

Demo Mini Perpustakaan (11 Oktober 2026) menunjukkan seluruh kegagalan QA berasal
dari test atau platform, bukan bug aplikasi: QA menambah syarat sendiri (UAC-4),
selector baris berulang ambigu, dan expected text ditebak dari UAC. Akar masalahnya:
tidak ada sumber kebenaran untuk tampilan, copy, state dan feedback. TL menulis
kontrak UI sekaligus wording, Developer menebak gaya, QA menebak teks.

Role UI/UX baru menghasilkan spesifikasi UI (UiSpec) sebelum TL. Kontrak UI,
implementasi, dan expected value QA diturunkan dari spesifikasi itu.
